Typing slips for AI-drafted messages

Paste clean text and get it back the way people type: contractions, lowercase starts, the odd typo. 4 styles, free in your browser and in Claude Code.

Works inside Claude. Your assistant writes, the function adds the slips.

  1. Add the server to Claude Code

    One command adds the MCP server. Other MCP apps take the same address.

  2. Connect the Claude app

    In Settings, open Connectors, add a custom connector and paste the address.

  3. Install the Claude Code skill

    Claude rewrites the text in your voice first. Save 5 to 10 of your messages as voice-samples.md.

  4. Run the server on your machine

    The same server over stdio, so your text never leaves your computer. Needs Node 22.18 or newer.

Terminal

  1. # Claude Code: add the MCP server

    claude mcp add --transport http humanize-typing http://localhost:3100/api/mcp

  2. # Claude app: Settings, Connectors, add a custom connector

    http://localhost:3100/api/mcp

  3. # Claude Code skill: rewrites in your voice first

    mkdir -p ~/.claude/skills/humanize-typing && curl -fsS http://localhost:3100/humanize-typing/SKILL.md -o ~/.claude/skills/humanize-typing/SKILL.md

  4. # Local server: text stays on your machine

    claude mcp add humanize-typing -- node /path/to/humanize-typing/src/lib/mcp-stdio.ts

  5. # Then, in Claude

    humanize this message

Questions

Where does my text go?

On this page, nowhere. The hosted MCP server changes it in memory and sends it back without storing it. The local server keeps it on your machine.

What does Humanize typing cost?

Nothing. There is no model behind it and no account to make.

Which links does Humanize typing skip?

Links, email addresses, file paths and anything with a digit. Typos skip capitalised words and words under four letters.

Does Humanize typing lowercase names?

Sometimes, when a name starts a sentence. Check names before you send.

Real typing is uneven. Some messages are clean, some have five slips.

Ask a model to add mistakes and it spreads them evenly, one typo per message. Humanize typing draws a mess level for every run, and one typo makes the next more likely in the same sentence.
